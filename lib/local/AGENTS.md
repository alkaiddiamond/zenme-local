# Local Data Instructions

- 用户项目、画布、阅读资料、设置和用量统计只写入解析后的 Zenme 数据根目录。
- 所有用户输入的路径段必须经过 `path-safety.ts`；禁止拼接未经校验的绝对路径、`..`、UNC 或路径分隔符。
- JSON 写入复用原子写入工具；写入失败不能破坏最后一个有效版本。
- 持久化 schema 变化必须提供向前迁移、旧 fixture 回归测试和失败恢复路径，不得静默丢弃未知字段。
- 备份默认排除 API Key、OAuth Token 和其他密钥；恢复前先在临时目录验证，再原子切换。
- 测试统一使用系统临时目录并在结束后清理，不得使用开发者真实数据目录。
