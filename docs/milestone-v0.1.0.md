# Zenme Local 0.1.0 里程碑

日期：2026-07-10

## 里程碑定义

0.1.0 是 Zenme Local 独立本地桌面应用的首个功能基线。此版本冻结当前项目管理、无限画布、文本与图片 AI、阅读体系、模型配置和本地备份恢复的行为，作为后续优化与回归比较基准。

## 数据与安全边界

- 所有业务数据保存在用户本机数据目录。
- 不包含账号、远程数据库、云端对象存储或自动同步代码。
- 本地服务只监听 loopback，并拒绝跨源管理请求。
- 备份不包含模型 API Key，恢复经过容量与路径校验。

## 功能基线

- 桌面窗口、侧栏、项目 Tab、项目搜索与重命名。
- 无限画布、节点连接、分组、历史、自动保存和缩略图。
- 统一文本节点及文本 AI 续写。
- 图片编辑、模型/尺寸选择、结果覆盖、全屏与下载。
- PDF/EPUB/TXT 阅读、进度、标注、笔记和 OCR。
- 模型服务商、真实模型 ID、别名、模态、启用状态和分类偏好。
- 数据目录选择、备份与恢复。

## 发布门禁

- `npm run lint`
- `npm test`
- `npm run build`
- `npm run desktop:pack -- --publish never`
- 运行时代码和依赖中无已移除远程数据服务残留

## 后续版本原则

- 不破坏 0.1.0 数据目录格式；必要变更必须提供版本化迁移。
- 优先拆分大型协调组件和补齐真实服务、桌面升级与压力测试。
- 新增联网能力必须显式、可关闭，且不能改变本地数据所有权。
