# Zenme Local 阅读体系需求

## 1. 定位

阅读能力是无限画布的一部分。书籍、阅读器、标注和笔记都属于当前项目，并完全保存在项目本地目录中。

## 2. 支持格式

- PDF：分页渲染、缩放、目录和文本/区域笔记。
- EPUB：章节导航、资源读取和阅读进度。
- TXT：文本阅读、位置恢复和笔记。

## 3. 交互要求

- 用户可将支持的文件拖入画布或通过上传窗口选择文件。
- 导入后创建书籍节点；打开阅读器后可最小化为画布节点。
- 阅读器包含目录、正文和笔记区，记录当前章节/页码、阅读位置和缩放。
- 最小化后再次打开时，正文与目录都跳转到上次位置。
- 阅读笔记可创建为画布文本节点，保留来源资料与定位信息。
- 点击笔记节点后显示统一文本 AI 对话控件。

## 4. 本地数据

每份资料位于 `projects/{projectId}/reading/{assetId}/`，包含：

- `asset.json`：标题、类型、原文件名、时间与展示元数据。
- `sections.json`：解析后的章节/页信息索引。
- `notes.json`：笔记、标注、颜色和来源定位。
- `progress.json`：当前位置和阅读视图状态。
- `original/`：原始文件。
- `cover.webp`：可选封面。

所有 `projectId`、`assetId` 和资源相对路径必须通过安全路径校验。删除项目时一并删除其阅读资料。

## 5. OCR

- 默认使用本地 Tesseract，支持中英文识别。
- 外部 OCR 需要用户显式配置，不作为阅读资料保存的前置条件。
- OCR 错误不得向界面泄露本机绝对路径或敏感配置。

## 6. 验收

- 断网时仍可导入、打开、阅读、记录进度和创建笔记。
- 关闭并重启应用后可恢复资料、进度、标注和笔记。
- 阅读器最小化再打开后，目录与正文定位一致。
- 备份恢复后，阅读资料和画布引用保持有效。
