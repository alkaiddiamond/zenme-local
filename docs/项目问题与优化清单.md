# 项目问题与优化清单

基线日期：2026-07-10

## 本里程碑已解决

- 移除账号、远程数据库、云端存储、迁移脚本及双数据源分支。
- 本地管理 API 增加 loopback 与同源边界。
- 备份移除 API Key，恢复增加容量预算、完整校验、原子切换和失败回滚。
- 画布、缩略图与项目文件增加结构和容量限制。
- Electron 限制跨源导航、外部协议和权限请求。
- 模型调用按服务商协议分派，图片模型与文本模型分流。
- 节点记录真实模型，文本与图片分别保存最近模型偏好。
- 移除无消费者设置、角色模型映射和新建历史文本生成节点入口。
- 自动保存间隔接入实际画布行为。

## 后续优化

- 拆分 `canvas-client.tsx`、`settings-client.tsx` 和 `reading-workspace.tsx` 的状态与视图职责。
- 为真实 Zhipu/OpenRouter 调用建立可选集成测试，避免 CI 消耗用户额度。
- 增加 Windows 安装升级、数据目录切换和超大项目压力测试。
- 跟踪 Next.js 生产依赖安全公告并在兼容版本发布后升级。

详细审计与处置依据见 [code-audit-2026-07-10.md](code-audit-2026-07-10.md)。
