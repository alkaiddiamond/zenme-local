# Zenme Local PRD

版本：0.1.0
基线日期：2026-07-10
状态：当前实现基线

## 1. 产品定位

Zenme Local 是面向个人创作、阅读与 AI 辅助工作的本地桌面无限画布。用户可以在一个项目中组织文本、图片、文件、书籍、笔记和 AI 生成结果，并通过连线表达上下文关系。

产品坚持以下边界：

- 纯本地、单用户、桌面优先。
- 无账号、无远程数据模式、无自动上传或云同步。
- 用户数据由本机文件系统持有，数据目录可查看、迁移、备份和恢复。
- 模型调用是唯一需要联网的核心能力，密钥由用户自行配置并保存在本机。

## 2. 应用结构

### 2.1 桌面壳

- Electron 提供原生窗口、任务栏图标、自绘标题栏、窗口控制与数据目录能力。
- 应用服务只绑定 `127.0.0.1`；管理 API 拒绝非 loopback、跨源和跨站请求。
- 主窗口不得导航到外部页面；HTTP(S) 外链交给系统浏览器。

### 2.2 项目工作区

- 左侧侧栏包含新建项目、搜索、固定顺序项目列表、首页、设置和本地模式状态。
- 顶部显示已打开项目 Tab，支持切换、关闭和重命名；打开项目不改变列表顺序。
- 侧栏可收起；窗口布局和滚动区域不得侵入标题栏。

## 3. 项目与本地持久化

- 支持新建、打开、搜索、重命名和删除项目。
- 搜索栏下方提供“收藏”区；用户可从项目菜单添加收藏或取消收藏，收藏项目同时在完整项目列表名称前显示实心星标，并在收藏区提供快捷入口。
- 收藏与置顶相互独立：收藏不改变完整项目列表顺序；删除项目时同步清理收藏记录，搜索条件同时作用于收藏区与项目列表。
- 左侧项目列表的 `...` 菜单提供“添加收藏/取消收藏”“置顶/取消置顶”和“删除”；项目重命名继续使用项目行的独立入口。
- 删除项目属于不可恢复的危险操作，必须显示二次确认弹窗，明确展示项目名称及将被删除的画布和本地文件；只有用户再次点击“删除项目”才执行删除。
- 删除成功后必须同步清理项目列表、置顶记录、固定顺序和已打开标签；删除当前项目时跳转到下一个仍然存在的已打开项目，没有可用项目时返回首页。
- 项目元数据、画布快照、缩略图、普通文件和阅读资料均位于项目目录。
- 自动保存间隔由本地设置驱动，默认 5 秒。
- 保存状态只表达本地保存结果，不出现云端同步文案。
- 项目和节点 ID 必须是安全路径段，任何 API 都不得据此写出数据目录。

## 4. 无限画布

- 支持平移、缩放、框选、拖拽、连线、分组、撤销与重做。
- 连线支持点击和键盘焦点选中，并按普通淡色、端点节点选中中色、连线选中重色三级展示；所有级别保持一定透明度以呈现交叉叠加，选中后可使用删除快捷键移除。
- 鼠标位于画布空白区、节点内容或节点控件上时，均支持 `Ctrl/Cmd + 滚轮` 以鼠标位置为中心缩放画布；无修饰键的滚轮继续用于节点内部滚动。
- 画布缩放范围为 `20%–250%`，所有按钮、滚轮和视口恢复逻辑使用同一边界。
- 节点端点位于内容框纵向中点；未连接的输入端点不显示。
- 输出侧显示 `+` 快捷入口，可继续创建并连接下游节点。
- 节点选中时显示统一边框与悬浮工具栏；点击节点内容区域即可选中。
- 支持重命名的节点在编辑标题时必须显示文本插入光标，并暂时隐藏格式工具栏、AI 对话控件、连接控件和缩放手柄；提交或取消后恢复。
- 拖动节点期间隐藏节点悬浮控件、连接控件、缩放手柄和多选工具条，拖动结束后恢复，避免控件遮挡画布和产生误操作。
- 悬浮工具栏和下方对话控件采用屏幕尺度补偿，缩放画布时保持可用尺寸并相对节点居中。
- 画布支持 `Ctrl/Cmd+C`、`Ctrl/Cmd+X` 和 `Ctrl/Cmd+V` 复制、剪切及粘贴所选节点；粘贴时生成新节点 ID、保持节点相对布局和分组关系，但不复制任何连线。
- 粘贴创建的节点默认不选中、不获取输入焦点，也不改变粘贴前已有节点的选择状态。
- 系统剪贴板中的一张或多张图片可直接粘贴为本地图片节点，并沿用项目文件上传、预览和持久化链路。
- 系统剪贴板中的纯文本可直接粘贴为文本节点；焦点位于输入框、文本编辑器或可编辑区域时保留系统原生复制粘贴行为。
- 粘贴位置优先采用鼠标最近所在的画布坐标，无法取得时使用当前画布视口中心。
- 画布快照限制为 20 MB、5000 个节点和 10000 条边；缩略图限制为 WebP 且不超过 5 MB。

## 5. 文本节点

- 文本、Markdown 和代码片段统一为文本节点，不再提供新的独立文本生成节点入口。
- 顶部工具栏保留粗体、斜体、下划线、行内代码、新增内容及显示模式切换。
- 显示模式包括纯文本、Markdown、代码；代码模式可选择语言。
- AI 文本回复默认按 Markdown 模式记录和展示，支持标题、列表、引用、行内代码及代码块；历史 AI 回复也按 Markdown 解释，不再以保留 Markdown 符号的纯文本方式展示。
- 模式切换、失焦与重新聚焦不得清空内容。
- 点击文本节点后，在下方展开 AI 对话控件；输入提示词后，基于节点内容和上游上下文生成结果。
- 阅读笔记等文本类节点采用相同的下方对话交互。
- 历史 `textGeneration` 节点继续兼容渲染，但不能再新建。

## 6. 图片生成与参考图处理

- 上传图片和生成图片采用同一画布显示算法；相同宽高比必须得到相同显示尺寸，不因图片来源或实际像素数而变化。
- 所有图片框采用同一外接圆规则：以 `280 × 280` 正方形的对角线作为固定直径，按图片真实宽高比计算内接矩形；任意比例均保持相同对角线长度，不限制为预设比例区间。
- 非标准比例读取图片实际宽高计算，不强制归入预设比例；源文件分辨率只影响下载结果。
- 上传图片的画布预览采用最长边 `1200px`、质量 `0.88` 的 WebP；本地原图保持原始字节，用于最大化查看、下载和后续图片处理。
- 图片上方白色工具栏提供全屏查看和下载。
- 下载文件名使用可追溯的时间戳/元数据命名。
- 图片能力统一使用“图片生成”节点，不再向用户提供独立的“图片编辑”节点；节点上部为结果框，下部为获得焦点后展开的提示词控件。
- 图片生成和图片编辑不是两种节点类型，而是同一节点根据参考集合产生的任务语义：没有参考图时以纯生成为主；存在参考图时，根据用户指令执行精确编辑或以参考图为基础生成新图片。
- 旧画布快照首次读取时必须从 `v1` 一次性迁移并原子回写为 `v2`：旧 `imageEdit` 节点转为 `imageGeneration`，旧图片任务字段转为统一字段，参考关系由连线恢复，并清除节点内重复保存的来源 URL；迁移后运行时和新快照不得继续写入旧结构。
- 文本和图片生成节点的默认主节点尺寸统一为 `520 × 260`；浮动控件不得反向改变主节点基础尺寸。
- 双击画布或从图片节点的关联操作入口均创建“图片生成”节点；从现有图片创建时自动建立连线并将该图片选为参考。
- 图片生成节点的输入控件顶部提供参考图片区；输入独立的 `@` 或点击“+”打开参考选择器，选择器支持搜索当前已连接的图片节点和多选。
- 参考选择器默认关闭，选择或重新选择节点不得自动展开；只有新的 `@` 输入或用户点击“+”才触发打开。
- 从选择器选中一张参考图片后立即关闭面板；已选引用名称最多显示 10 个字符，超出部分使用 `...`，完整名称保留在悬停提示中。
- 连线图片只作为候选，不自动全部提交；用户明确选中的图片显示为顶部缩略图及引用标签，支持从缩略图取消引用。
- 已选参考集合必须持久化，并与实际模型请求完全一致；图片生成最多接收 8 张参考图，断开连线后立即从候选、已选区和下一次请求中移除。
- 图片生成节点完成后仍保留“生成”任务身份，再次提交时继续按当前已选参考集合生成。
- 普通图片和图片生成节点均支持双击节点标题重命名；重命名期间隐藏节点的其他浮动控件，生成完成后不得用默认名称覆盖用户标题。
- 生成结果覆盖节点内部的上次结果，不创建额外结果节点；重新生成期间保留旧图，成功后再原位替换。
- 图片生成或编辑任务开始后在节点右上角显示实时耗时；成功后记录并持久化最终耗时，刷新画布后仍可查看。
- 图片结果上传完成后必须立即提交包含结果引用的画布快照，不能只依赖定时自动保存；避免刷新发生在文件落盘与节点保存之间时形成孤立结果。
- 页面刷新或应用重启后，快照中遗留的 `editing` 状态必须转为可重新提交的失败状态，不能继续伪装为正在执行。
- 输入图片由上游图片节点连线提供，连接点位于结果框中点。
- 图片节点的输入、输出和操作连接点必须相对实际图片框垂直居中，不能把图片上方标题高度计入中心位置。
- 图片生成与编辑请求必须使用已启用且包含“图片”模态的模型；当前支持 OpenRouter 图片模型和 ChatGPT GPT-5.6 Sol。
- GPT-5.6 Sol 通过 ChatGPT OAuth Responses 路线调用托管的 `image_generation` 工具：没有参考图时执行纯生成；存在参考图时进入参考图处理模式。
- 无参考图时系统提示词要求按描述创建图片；有参考图时根据用户指令在精确编辑和基于参考重新生成之间判断，多张参考图可分别用于主体、造型、风格、场景或构图。

## 7. 阅读体系

- 支持 PDF、EPUB、TXT 导入、书籍节点、阅读器节点和阅读工作区。
- 阅读器包含目录、正文与笔记区域，记录当前位置、缩放、标注和笔记。
- 阅读器最小化后重新打开必须恢复当前位置并滚动到当前目录项。
- 笔记可以生成画布文本节点，并继续参与节点上下文与 AI 对话。
- OCR 支持本地 Tesseract；外部 OCR 仅在用户显式配置时调用。

## 8. 模型配置

- 服务商配置包含名称、地址、API 格式、认证方式、密钥和启用状态。
- 模型配置包含真实模型 ID、可选别名、上下文窗口、模态和启用状态。
- 服务商和模型不存在全局“默认”状态；节点按用户当前选择或该模态上次使用记录决定模型，并由模型 ID 定位所属服务商。
- 模态包括文本、视觉、图片、向量、音频、排序和工具；节点只显示与自身能力匹配的启用模型。
- Zhipu 由用户手动拉取模型后选择添加；OpenRouter 不依赖全量拉取，可手动维护模型。
- 每个服务商可设置默认文本模型和默认图片模型，不使用 Haiku/Sonnet/Opus 角色映射。
- 文本与图片分别记录最近一次模型选择；新节点沿用同类节点偏好，模型失效时回退到对应默认模型。
- 图片类节点记录最近一次使用的模型、宽高比和画质；新建图片生成节点及普通图片的生成控件沿用最近一次组合，已有节点仍以自身保存的配置为准。
- 文本和图片请求均按模型所属服务商协议分派；图片节点可在 OpenRouter 图片模型与 ChatGPT GPT-5.6 Sol 之间选择。
- ChatGPT 作为内置服务商提供，不使用 API Key 表单，也不可按普通自定义服务商删除。
- 用户点击“登录 ChatGPT”后，应用通过系统浏览器完成 OpenAI OAuth PKCE 登录；本机临时回调仅监听 `localhost:1455/auth/callback`，登录成功后自动拉取该账号可用的 Codex 模型。
- ChatGPT 模型列表来自账号模型接口并支持手动重新同步；同步结果进入统一模型配置，文本节点只显示启用且包含“文本”模态的模型。
- ChatGPT 模型同步使用经过验证的 Codex 协议兼容版本，服务端返回结果仍按账号套餐和 `minimal_client_version` 决定；`visibility=hide` 的内部模型不展示给用户。
- ChatGPT access token、refresh token 仅保存在本地数据目录的私有令牌文件中，不进入前端状态、设置 JSON、日志或本地备份；访问令牌临近过期时自动刷新，退出登录后立即删除。
- ChatGPT OAuth、模型同步和 Responses 请求应遵循本机 `HTTPS_PROXY` / `HTTP_PROXY` / `ALL_PROXY` 与 `NO_PROXY`，保证浏览器授权和服务端交换使用一致的网络出口；代理地址不进入前端或日志。
- ChatGPT 文本调用使用 Zenme 自有系统提示词和 OpenAI Codex Responses 路线，不复用 Claude Code 的系统提示词。
- 保存服务商设置后弹窗保持打开并显示保存状态。

## 9. 备份与恢复

- 设置页支持下载 ZIP 备份和恢复本地备份。
- 备份排除模型 API Key。
- 恢复限制压缩包大小、条目数与解压总量，拒绝绝对路径、盘符和路径穿越。
- 恢复必须先在临时目录完整验证，再原子切换；失败时自动回滚原数据目录。

## 10. Token 用量

- 设置页提供“Token 用量”视图，数据只保存在本地数据目录，不依赖云端账户或远程数据库。
- 统计内容包括累计 Token、单日峰值、最长生成耗时、当前/最长连续活跃天数、调用总数和文本/图片调用次数。
- 活动趋势支持每日热力图、每周汇总和累计视图，并展示最常用模型及服务商排行。
- Token 数仅采用服务商响应中明确返回的 usage 数据；服务商未返回用量时记录调用与耗时，但 Token 数保持为零，不在客户端估算。
- 统计从功能启用后的模型调用开始积累，不伪造或反推此前的历史数据。
- 用量记录只包含数量、模型、服务商、模态、时间和耗时，不保存提示词、生成内容、API Key 或 OAuth Token。

## 11. 非功能要求

- 设计遵循 [design-standard.md](design-standard.md)。
- 节点必须保持明确的悬浮阴影，与无限画布形成稳定的纵深关系；缩放画布后也不能因样式失效而完全失去阴影。
- 阴影必须通过设计标准定义的全局语义令牌和语义类实现，语义类直接设置 `box-shadow`；禁止使用会被 Tailwind 误判为阴影颜色的 `shadow-[var(--shadow-*)]` 写法。
- 阴影相关改动的验收必须检查编译后的 CSS 或运行时计算样式，不能仅依据源码中存在阴影类名判断功能已生效。
- 生产构建、单元测试和 ESLint 是里程碑质量门禁。
- 桌面目录包必须能生成并完成冷启动检查。
- 不在日志、接口错误、备份或文档中泄露模型密钥及本机绝对业务路径。

## 12. 当前不包含

- 多用户、账号体系、在线协作、远程数据库和自动云同步。
- 移动端适配与浏览器公网部署。
- 未实现协议的模型能力；设置项不得承诺实际适配器不支持的调用。

## 13. 后续演进

- 将大型画布、设置和阅读工作区组件继续按状态、命令、请求与视图边界拆分。
- 增加真实模型端到端测试、桌面升级覆盖测试和大数据目录压力测试。
- 在不改变本地数据所有权的前提下评估可选加密密钥存储。
