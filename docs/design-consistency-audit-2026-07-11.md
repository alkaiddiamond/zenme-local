# Zenme 设计一致性审计

审计日期：2026-07-11  
审计基准：`docs/design-standard.md`

## 审计范围

- 桌面应用壳层：标题栏、侧边栏、项目列表、顶部标签栏。
- 首页与设置：内容层级、导航状态、弹窗、按钮、表单与统计视图。
- 无限画布：背景、控制栏、菜单、提示与错误反馈。
- 节点体系：文本、Markdown、代码、图片、图片生成、图片编辑、阅读器。
- 节点交互：选中、悬停、编辑、拖动、连接端点、浮动工具栏和下方输入控件。

## 已修复问题

| 类别 | 原问题 | 修复结果 |
| --- | --- | --- |
| 设计令牌 | 危险色、成功色及画布/遮罩阴影缺少统一令牌 | 在全局 CSS 中补齐语义色和三类阴影令牌 |
| 视觉语言 | CSS 中仍保留未使用的渐变按钮变量 | 删除渐变变量，主操作继续使用纯色 |
| 字重 | 设置页多处界面标题使用 `600` | 常规界面统一为 `500`；统计数字和用户内容保留例外 |
| 导航状态 | 设置导航用整块底色表示选中 | 改为文字强调，避免与侧边栏规范冲突 |
| 标签状态 | 顶部活动标签额外使用白色块背景 | 仅保留字重和底部活动线 |
| 圆角 | 菜单、提示、侧面板和阅读器混用 16px 以上圆角 | 普通控件收敛到 8px，节点/大型工具面板使用 12px |
| 阴影 | 节点、菜单、工具栏和弹窗散落使用多档 Tailwind 阴影 | 分别改用节点、画布、下拉和遮罩阴影令牌；节点令牌保留原 `shadow-xl` 的悬浮效果 |
| 节点输入 | 图片编辑下方输入控件宽度与文本节点不一致 | 统一为 560px，并保留视口最大宽度约束 |
| 节点标题 | 图片类节点标题字号与其他节点不同 | 统一为 12px、500 字重及稳定标题行高度 |
| 装饰元素 | 图片预览背景含径向渐变装饰 | 删除装饰渐变，保持内容优先 |
| 首页表面 | 首页输入区使用过强阴影和过大圆角 | 改为 8px 圆角并移除无必要阴影 |

## 核验结论

- 应用 UI 已不再使用渐变背景或装饰性光斑。
- 普通界面字重以 `400/500` 为主；`600` 仅用于指标数字、阅读正文标题和 Markdown/代码内容。
- 强阴影不再直接散落在业务组件中，节点与浮层层级由不同语义令牌表达。
- 节点主表面、上方工具栏和下方输入控件形成统一层级。
- 活动导航、活动标签、节点选中与错误状态使用不同且稳定的反馈方式。

## 允许的例外

- Markdown 的 H1/H2/H3 和代码语法高亮属于用户内容排版，可使用 `600` 字重。
- Token 统计大数字属于关键指标，可使用 `600` 字重和更大字号。
- 节点与阅读器属于大型工具表面，可使用 12px 圆角；胶囊工具栏和圆形图标按钮按其几何语义使用全圆角。
