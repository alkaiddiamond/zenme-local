# Zenme 设计标准

本文档记录 Zenme Local 当前桌面应用的视觉与交互标准。后续新增页面、组件或重构样式时，应优先遵循这里的规则。

## 设计原则

- 以工作台为第一屏，不做营销式首页。
- 整体气质参考 cc-haha：冷灰白、安静、轻量、偏工具化。
- 页面优先服务重复使用和快速扫描，不使用夸张 hero、装饰渐变、浮动大卡片。
- 视觉层级靠间距、边框、浅 hover 和少量字重区分，不靠大面积色块。
- 本地优先语义必须清晰，避免“云端”“同步”等旧文案误导。

## 色彩

基础色来自 `app/globals.css` 的 CSS 变量：

- 主背景：`--color-surface: #ffffff`
- 侧栏背景：`--color-surface-sidebar: #f3f6fa`
- 顶栏背景：`--color-surface-topbar: #f8fafc`
- 浅容器：`--color-surface-container-low: #f7f9fc`
- hover 容器：`--color-surface-container-high: #edf1f6`
- 主文字：`--color-text-primary: #111827`
- 次级文字：`--color-text-secondary: #4b5563`
- 弱文字：`--color-text-tertiary: #8b95a5`
- 边框：`--color-border: #e3e8ef`
- 强边框：`--color-border-strong: #d5dce7`
- 品牌强调：`--color-brand: #8f482f`
- 运行/提交按钮：`--color-run: #ead5cf`
- 顶部 tab 激活线：`--color-tab-active: #8f482f`

使用规则：

- 默认状态尽量透明，不给按钮和导航项铺大面积背景。
- hover 使用 `--color-surface-container-high`，不要直接用醒目的品牌色。
- 品牌色只用于选中下划线、关键边框、少量强调，不铺满页面。
- 不使用蓝色作为主视觉；截图中的蓝色圆点是鼠标控件，不属于产品色彩。
- 不使用大面积紫色、蓝紫渐变、米黄/棕色主题。

## 字体与字重

字体定义：

- 正文：`--font-body`，当前为 `Inter` + 中文系统字体。
- 标题：`--font-headline`，当前为 `Manrope` + `Inter` + 中文系统字体。
- 代码：`--font-mono`，当前为 `JetBrains Mono`。

字重规则：

- 默认正文使用 `font-normal`。
- 导航、项目名称、卡片标题默认不使用粗体。
- 选中态可以用 `font-medium`，不要用 `font-semibold` 或 `font-bold`。
- 一级页面标题最多使用 `font-medium`，多数工作台标题使用 `font-normal`。
- 不为了强调随意放大字号；工具面板、侧栏、tab 使用紧凑字号。

推荐字号：

- 顶部 tab：`text-sm`
- 侧栏项目：`text-sm`
- 侧栏分组标题：`text-xs`
- 首页提示文案：`text-sm font-normal`
- 首页区块标题：`text-base font-normal`
- 项目卡片名称：`text-sm font-normal`

## 布局

桌面应用采用三层结构：

- 左侧项目工作栏：宽度 `280px`，收起后 `48px`。
- 顶部 tab 栏：高度 `40px`，从侧栏右侧开始。
- 主内容区：从侧栏和顶部 tab 下方开始。

布局规则：

- 画布页必须使用父容器高度，不能再用裸 `100vh` 抢占整屏。
- 页面主体不要嵌套卡片式大容器；内容应直接排布在主区域。
- 固定格式元素要有稳定尺寸，避免 hover、图标、动态文字导致布局跳动。
- 左侧侧栏收起/展开时，顶部 tab 和主内容需要同步改变左边距。

## 左侧侧栏

侧栏内容顺序：

1. 顶部：展开/收起按钮、logo、产品名。
2. 操作区：新建项目、搜索项目。
3. 项目列表：固定顺序、置顶优先。
4. 底部：首页、设置、本地模式入口。

交互规则：

- 侧栏按钮默认透明，不显示块状背景。
- hover 才显示浅灰背景。
- 当前项不显示白色卡片背景，只加深文字或使用 `font-medium`。
- 项目列表顺序必须稳定，点击/打开/保存项目不能重排。
- 新项目插入列表顶部。
- 置顶项目显示在最上方，置顶组内部保持固定顺序。
- 项目操作入口使用图标按钮，提供重命名和置顶。

## 顶部 Tab

顶部 tab 用于管理已打开项目。

规则：

- tab 顺序保持打开顺序，不因点击切换而重排。
- 新打开项目追加到末尾，最多保留 9 个项目 tab。
- 当前 tab 使用底部品牌色细线表示激活态。
- 项目 tab 可关闭；关闭当前项目时跳到相邻已打开项目或首页。
- 当前项目 tab 点击可打开重命名弹层。
- 重命名使用统一弹层，不在顶部和侧栏同时渲染 inline 输入框。

窗口控制：

- Electron 使用无框窗口。
- 顶部栏中可拖拽区域用 `data-desktop-drag-region`。
- 所有按钮、输入框、tab、菜单必须在 `data-desktop-no-drag` 区域内。

## 按钮

通用规则：

- 有明确图标时优先使用 `lucide-react` 图标。
- 工具按钮使用图标按钮，不用文字胶囊替代熟悉图标。
- 默认按钮透明或白底，避免大面积色块。
- hover 使用浅灰背景。
- 危险动作使用红色 hover 或红色文字，不默认高亮。
- 主提交/运行按钮使用 `--color-run`，不使用高饱和品牌色。

侧栏按钮：

- 默认透明。
- 当前态不铺背景。
- hover 可用 `--color-surface-container-high`。

## 输入框与搜索框

规则：

- 搜索框使用白底、浅边框、圆角。
- 输入框 focus 使用 `--color-border-focus` 或轻微 ring。
- placeholder 使用 `--color-text-tertiary`。
- 输入框文字默认 `font-normal`。

## 卡片与项目网格

项目卡片：

- 用于项目缩略图和标题，不做装饰性厚重卡片。
- 缩略图区域使用浅边框和固定比例。
- 标题使用 `text-sm font-normal`。
- 时间/状态使用 `text-xs` 和弱文字。
- hover 可改变边框色，不增加强阴影。

新建项目卡片：

- 保持和项目卡片相同尺寸。
- 使用加号图标。
- 默认不使用强背景，hover 才显示轻微强调。

## 画布

画布原则：

- 画布是主要工作区，控件不能遮挡内容边界。
- 画布根容器应使用 `h-full`，由外层布局控制高度。
- 浮动工具栏使用白底、浅边框、轻阴影。
- 保存状态文案必须使用本地语义：
  - `正在保存到本地`
  - `已保存到本地`
  - `本地保存失败`
  - `本地服务不可用`
- 不使用“保存到云端”等云端文案。

## 本地化与文案

文案规则：

- 默认使用简体中文。
- 本地优先功能使用“本地”“数据目录”“备份”“恢复”等表达。
- 不在本地模式 UI 中出现“云端”“Supabase”“同步”等旧概念，除非明确在设置中展示实验性云同步。
- 按钮文字要短，例如：`新建项目`、`重命名`、`置顶`、`取消置顶`、`保存`。
- 不在界面中写教程式说明；必要说明放到文档或设置页帮助区。

## Logo 与图标资源

当前主 logo：

- 源文件：`zenme-logo.png`
- 主资源：`public/brand/zenme-logo.png`
- 图标尺寸目录：`public/brand/icons/`
- 任务栏图标：`public/brand/icons/zenme-logo-256.png`

生成尺寸：

- `16`
- `24`
- `32`
- `48`
- `64`
- `128`
- `256`
- `512`
- `1024`

使用规则：

- 应用窗口和任务栏使用方形图标。
- 不再使用横向裁切版作为任务栏图标。
- 页面左上角 logo 使用 `public/brand/icons/zenme-logo-256.png`。

## 代码约定

- 优先使用 CSS 变量，不直接散落硬编码颜色。
- Tailwind 类中可以引用 `var(--color-*)`。
- 新增组件优先复用现有布局节奏和间距。
- 不新增装饰性渐变、浮动大卡片或无功能视觉元素。
- 页面改动后至少运行：
  - `npm run lint`
  - `npm run build`
